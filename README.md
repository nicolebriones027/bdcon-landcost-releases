# BDCON LandCost — releases

Installers and update files for **BDCON LandCost**, BD Con Land Development Company's offline app for PDF plan to CAD conversion, quantity takeoff and estimating.

This repository holds only finished installers. The source code is private.

## Install

1. Open **[Releases](../../releases/latest)** and download `BDCON-LandCost-Setup-<version>.exe`.
2. Run it. If Windows shows "Windows protected your PC", click **More info → Run anyway** (the installer is not code-signed yet).
3. Choose the install options and finish. No internet connection is needed to install or use the app.

## Updates

Installed copies check this page for a newer version when the computer is online (at start-up, or with **Settings → Check for updates**), download it and install it on **Restart to update**. Projects, rates and settings are kept. You can also run a newer installer over an older version.

## DWG output

To save DWG (not only DXF), install the free **ODA File Converter** from opendesign.com. The app finds it automatically, or set its location in **Settings**.
